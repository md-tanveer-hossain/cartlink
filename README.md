## Features
- **60-Second Self-Serve Onboarding:** Sign in with Google, pick a custom `?shop=` slug, and launch immediately.
- **Zero Platform Fees:** Dynamic UPI QR codes route payments directly to the seller's bank account.
- **One-Tap WhatsApp Receipts:** Automatically formats items, quantities, total, Order ID, and 12-digit UPI reference into a ready-to-send WhatsApp message.
- **Real-Time Admin Dashboard:** Toggle stock status (`In Stock` / `Sold Out`), add items with images, and generate printable store QR codes.

## Tech Stack
- **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript (ES Modules)
- **Backend & Auth:** Firebase Authentication (Google Sign-In) & Cloud Firestore
- **Hosting:** GitHub Pages
